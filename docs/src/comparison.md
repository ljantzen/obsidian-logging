# obsidian-logging vs. Obsidian CLI

Obsidian now ships its own native CLI tool (available as Early Access with a Catalyst License) — see
the [Obsidian CLI documentation](https://help.obsidian.md/cli) for details. The two tools solve
different problems and can coexist happily.

## Use `obsidian-logging` if you want

- Quick, focused daily logging with timestamps
- Entries organized by category (work, personal, health, ...)
- Reusable phrase templates for common entries
- A lightweight tool optimized purely for fast note capture
- A free, open-source solution with no license requirement

## Use the Obsidian CLI if you need

- General vault operations and querying
- Advanced automation and scripting across your whole vault
- Plugin management
- Full programmatic control of Obsidian itself

For simple daily journaling from the command line, `obsidian-logging` is a small, dedicated tool that
does one thing well. For broader vault automation, Obsidian's native CLI offers much wider
capabilities.
